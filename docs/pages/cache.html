CacheManager + 命名缓存
v
import photon.cache // 1. 创建 CacheManager mut cm := cache.new_cache_manager() // 2. 注册命名缓存 cm.register('users', cache.new_memory_cache('users')) cm.register('products', cache.new_memory_cache('products')) // 3. 基本操作 cm.set('user:42', '{"name":"Alice"}', 300)! // TTL 300 秒 val := cm.get('user:42')! // '{"name":"Alice"}' cm.has('user:42') // true cm.delete('user:42')! // 删除 cm.clear()! // 清空默认缓存 // 4. 使用命名缓存 users_cache := cm.get_cache('users') users_cache.set('list', '[...]', 60)! // Spring 等价：@Cacheable / CacheManager // Laravel 等价：Cache::put('key', 'value', 300)

Cache 接口
实现自定义缓存后端
v
// Cache 接口 — 所有缓存后端必须实现 pub interface Cache { mut: get(key string) !string set(key string, value string, ttl_seconds int) ! delete(key string) ! has(key string) bool clear() ! keys() []string size() int } // 自定义 Redis 后端示例 pub struct RedisCache { client &RedisClient prefix string } pub fn (mut rc RedisCache) get(key string) !string { return rc.client.get('${rc.prefix}:${key}') } pub fn (mut rc RedisCache) set(key string, value string, ttl_seconds int) ! { rc.client.setex('${rc.prefix}:${key}', ttl_seconds, value)! } // ... 实现其他方法

Singleflight 防击穿
合并并发请求 · 防止缓存雪崩

当多个协程同时请求同一个缓存键时，Singleflight 确保只有一个协程实际执行加载逻辑，其余协程共享结果。

v
// CacheManager 内置 Singleflight // 并发请求 user:42 时，只有一个执行数据库查询 result := cm.singleflight_execute('user:42', fn () !string { // 只有第一个请求执行此函数 user := db.find_user(42)! json_data := user.json() cm.set('user:42', json_data, 300)! return json_data })! // Go 等价：golang.org/x/sync/singleflight
✨
@[cacheable] 注解
声明式缓存 — 方法级缓存抽象
v
@[component] pub struct UserService { @[autowired] cache_manager &cache.CacheManager @[autowired] user_repo &UserRepository } @[cacheable] pub fn (s &UserService) get_user(id int) !User { // 首次调用走数据库，后续走缓存 return s.user_repo.find_by_id(id)! } // Spring 等价：@Cacheable(value = "users", key = "#id") // Laravel 等价：Cache::remember("user:$id", 300, fn() => User::find($id))
⛓️
CacheOperation 链式 API
chain() · remember() · put() · get() · save() — 流式缓存操作

CacheOperation 提供链式 API 风格进行缓存操作，支持条件获取、写入、TTL 设置等，所有操作通过链式调用串联：

方法说明Spring 等价
cache.chain()创建 CacheOperation 链式操作起点CacheOperation.new()
.remember(key, ttl, loader)读取缓存，未命中时调用 loader 加载@Cacheable + cache-through
.put(key, value)设置缓存写入操作@CachePut
.ttl(seconds)设置过期时间（秒）@Cacheable.ttl
.save()执行写入操作（put 链式终点）cache.put()
.get()执行读取操作并返回结果cache.get()
v
import photon.cache mut cm := cache.new_cache_manager() cm.register('default', cache.new_memory_cache('default')) // CacheOperation 链式 API：remember 模式（读缓存 + 自动加载） value := cache.chain() .remember('users:1', 600, fn () !string { // 缓存未命中时调用此 loader 加载数据 user := db.find_user(1)! return user.json() }) .get()! println(value) // 首次走 db，后续 600s 内走缓存 // 链式 API：put 模式（写入 + TTL） cache.chain() .put('settings:theme', 'dark') .ttl(3600) .save()! // 链式写入示例 cache.chain() .put('user:42:prefs', '{"lang":"en","notify":true}') .ttl(7200) .save()! // Spring 等价：@Cacheable(value = "users", key = "#id") // Laravel 等价：Cache::remember("users:1", 600, fn() => User::find(1))
🔬
scan_cache_annotations
编译期注解扫描 · 自动注册缓存 · 声明式发现

scan_cache_annotations 在编译期扫描所有带 @[cacheable] 注解的 struct 和方法，自动提取缓存元数据，避免手动注册：

方法 / 类型说明Spring 等价
scan_cache_annotations编译期扫描所有 @[cacheable] 注解@EnableCaching + proxy scan
CacheAnnotation扫描结果（缓存名 / TTL / key 规则）CacheOperation
register_cache_annotations()自动注册扫描到的缓存配置CachingConfigurer
v
import photon.cache mut cm := cache.new_cache_manager() cm.register('default', cache.new_memory_cache('default')) // 编译期扫描所有带 @[cacheable] 的 struct 和方法 // 自动发现缓存注解，生成缓存操作元数据 annotations := cache.scan_cache_annotations()! for ann in annotations { println('Cache: ${ann.cache_name}, Key: ${ann.key}, TTL: ${ann.ttl}s') } // 自动注册到 CacheManager cache.register_cache_annotations(mut cm)! // 之后所有 @[cacheable] 方法自动生效 service.get_user(42)! // 自动命中缓存 // Spring 等价：@EnableCaching + @Cacheable auto-discover // Laravel 等价：Cache facade auto-discovery
🚀 生产实践
  • 设置合理的 TTL，避免缓存永不过期导致数据不一致
  • 使用 Singleflight 防止缓存击穿（热点 key 过期瞬间大量请求打到数据库）
  • 生产环境使用 Redis 后端，开发环境使用 Memory 后端
  • 缓存键使用 namespace:key 格式，避免冲突
  • 对序列化数据使用 JSON 格式，便于调试和跨语言读取
  • 使用 CacheOperation 链式 API 简化缓存写入逻辑，避免重复的 set/get 模式
  • 使用 scan_cache_annotations 在编译期发现缓存注解，实现声明式缓存自动注册
