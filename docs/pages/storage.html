pub interface Storage { mut: write(path string, content []u8, visibility Visibility) ! delete(path string) ! set_visibility(path string, visibility Visibility) ! pub: read(path string) ![]u8 exists(path string) bool metadata(path string) !FileMetadata size(path string) !i64 last_modified(path string) !i64 visibility(path string) !Visibility list(path string) ![]string copy(from string, to string) ! move(from string, to string) ! } // 可见性控制 pub enum Visibility { public_ // 公开可访问（CDN 可读） private_ // 私有（需签名 URL） }
🚫
❌ S3Adapter 已移除
所有方法均为桩实现 — 需自行实现云存储适配器
⚠️ S3Adapter 已从 photon.storage 模块中完全移除。移除原因：
  • S3Adapter 的所有操作（write、read、delete 等）均为桩实现（stub），不执行实际云存储操作
  • 维护空桩适配器会误导用户，造成生产环境数据丢失风险
替代方案：
  • 本地存储：使用 LocalAdapter — 功能完整，开箱即用
  • 云存储：自行实现 Storage 接口接入 S3 / OSS / COS 等

自定义云存储适配器示例

v
// 实现 Storage 接口接入 S3 / OSS / COS 等云存储 struct S3Storage { pub mut: bucket string region string client &http.Client } pub fn (mut s S3Storage) write(path string, content []u8, visibility storage.Visibility) ! { // 调用 S3 PutObject API } pub fn (s &S3Storage) read(path string) ![]u8 { // 调用 S3 GetObject API return []u8{} } // ... 实现其余 Storage 接口方法 // 使用自定义适配器 mut s3 := &S3Storage{bucket: 'my-bucket', region: 'us-east-1'} manager.register('s3', s3)
🚀 生产实践
  • 开发环境使用 Local 适配器，生产环境使用 S3
  • 上传文件使用 .private 可见性，通过签名 URL 按需授权
  • 使用 copy() 而非 read() + write() 在同存储间复制文件
  • 大文件使用分片上传（S3 multipart upload）
  • 文件路径使用 UUID 或哈希，避免路径冲突和信息泄露
