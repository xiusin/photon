💡 双 import 约定：由于 V 语言不允许同名模块互引，你需要同时 import 两个模块：import orm（V 原生）和 import photon.orm（Photon 增强）。

CRUD 操作 // 创建 mut user := User{name: 'Alice', email: 'alice@example.com', age: 30} user_repo.insert(mut user)! // 自动触发 before_insert → auto-touch → after_insert // 查询 found := user_repo.find_by_id(1)! // 按 ID 查询 all := user_repo.find_all()! // 全部查询 // 更新 mut existing := user_repo.find_by_id(1)! existing.name = 'Alice Updated' user_repo.update(mut existing)! // 自动更新 updated_at // 删除 user_repo.delete_by_id(1)! // 按 ID 删除 // Spring 等价：extends JpaRepository<User, Integer> // Laravel 等价：class UserRepository extends Eloquent

实体注解
JPA 风格注解 · 编译期实体映射

Photon ORM 提供 JPA 风格的注解系统，在编译期扫描实体元数据，实现声明式实体映射：

注解说明Spring JPA 等价
@[entity]标记 struct 为 JPA 实体@Entity
@[table('users')]指定表名@Table(name = "users")
@[column('user_name')]指定字段列名@Column(name = "user_name")
@[id]标记主键字段@Id
@[generated_value]自动生成主键@GeneratedValue
@[nullable]允许 NULL@Column(nullable = true)
@[length(255)]列长度@Column(length = 255)
@[precision(10)] / @[scale(2)]小数精度/标度@Column(precision=10, scale=2)
@[unique]唯一约束@Column(unique = true)
@[index('idx_name')]索引@Index(name = "idx_name")
@[transient]跳过持久化@Transient
@[enum_type('status_type')]枚举类型映射@Enumerated
@[embeddable] / @[embedded]嵌入值对象@Embeddable / @Embedded
@[version]乐观锁版本字段@Version
v
import photon.orm @[entity] @[table('users')] pub struct User { @[id] @[generated_value] id int @[column('user_name')] @[length(100)] @[nullable] name string @[column('email_address')] @[unique] email string @[column('age')] age int @[column('status')] @[enum_type('user_status')] status string @[version] version int @[transient] computed_field string } // scan_entity[T]() scans comptime annotations / 编译期扫描实体注解 meta := orm.scan_entity[User]() println(meta.table_name) // 'users' println(meta.columns.len) // number of mapped columns // validate[T]() validates entity constraints / 验证实体约束 result := orm.validate[User](user) if result.has_errors() { for err in result.errors { println('${err.field}: ${err.message}') } }

方法说明Spring 等价

import photon.orm mut repo := orm.new_base_repository[User](om, 'default')! // Find by field / 按字段查找 users := repo.find_by_field('status', 'active')! // Check existence / 检查是否存在 exists := repo.exists_by_field('email', 'alice@example.com')! // Count by field / 按字段统计 count := repo.count_by_field('status', 'active')! // Pagination / 分页查询 page_result := repo.paginate(1, 20)! // page 1, 20 per page println('Total: ${page_result.total}, Pages: ${page_result.total_pages}') for user in page_result.items { println(user.name) } // Spring equivalent: PagingAndSortingRepository // Laravel equivalent: User::paginate(20)

QueryBuilder 链式 API
new_query_builder · where_ · order_by · limit · get — 流式查询构建

QueryBuilder 提供链式 API 构建查询，支持条件、排序、分页等操作，最终通过 .get() 执行查询并返回结果：

方法说明Spring 等价
new_query_builder(manager, conn, table)创建 QueryBuilder 实例JPAQueryFactory
.where_(condition, ...args)添加 WHERE 条件（参数化查询）.where(predicate)
.where_and(conditions)批量 AND 条件.and(predicate)
.where_or(conditions)批量 OR 条件.or(predicate)
.order_by(field, direction)排序（.asc / .desc）.orderBy()
.limit(n)限制返回行数.limit(n)
.offset(n)偏移行数.offset(n)
.get()执行查询，返回结果集.fetch()
.first()返回第一条结果.fetchFirst()
.count()统计匹配行数.fetchCount()
v
import photon.orm mut manager := orm.new_orm_manager() manager.register_connection('default', .sqlite, db)! // 创建 QueryBuilder mut qb := orm.new_query_builder(manager, 'default', 'users') // 链式 API 构建查询 users := qb.where_('age > ?', 18) .where_('is_active = ?', true) .order_by('name', .asc) .limit(10) .get()! for user in users { println('${user.name} (${user.age})') } // 条件分组：AND / OR 条件 users2 := orm.new_query_builder(manager, 'default', 'users') .where_('status = ?', 'active') .where_and([ 'age >= ?', 18, 'age <= ?', 65, ]) .order_by('created_at', .desc) .offset(20) .limit(10) .get()! // 获取第一条（等价于 LIMIT 1） first_user := orm.new_query_builder(manager, 'default', 'users') .where_('email = ?', 'alice@example.com') .first()! // 统计匹配行数 total := orm.new_query_builder(manager, 'default', 'users') .where_('is_active = ?', true) .count()! // Spring 等价：queryFactory.selectFrom(user).where(...).orderBy(...).limit(10).fetch() // Laravel 等价：DB::table('users')->where('age', '>', 18)->orderBy('name')->take(10)->get()
🔒
ParamValue 类型安全 SQL
set_typed_exec_fn · 类型安全参数化查询 · SQL 注入防护

ParamValue 提供类型安全的 SQL 参数绑定机制，在编译期确保参数类型与 SQL 类型匹配，有效防止 SQL 注入，同时支持自定义执行函数：

类型 / 方法说明Java 等价
ParamValue类型安全参数值（int / string / bool / f64 / null）TypedQuery.setParameter()
set_typed_exec_fn(fn)注入自定义执行函数，用于类型安全查询JdbcTemplate
TypedExecFn类型安全执行函数签名RowCallbackHandler
v
import photon.orm mut repo := orm.new_base_repository[User](om, 'default')! // 注入类型安全的 SQL 执行函数 // 编译期验证参数类型，运行时防止 SQL 注入 repo.set_typed_exec_fn(fn (db voidptr, query string, args []orm.ParamValue) ! { // 自定义 SQL 执行逻辑 // args 是类型安全的 ParamValue 数组，编译期保证类型正确 for arg in args { match arg { orm.ParamValue { int 'int:' { val } { /* 处理 int 参数 */ } } orm.ParamValue { int 'string:' { val } { /* 处理 string 参数 */ } } orm.ParamValue { int 'bool:' { val } { /* 处理 bool 参数 */ } } orm.ParamValue { int 'f64:' { val } { /* 处理 f64 参数 */ } } orm.ParamValue { int 'null' {} { /* 处理 null */ } } } } }) // 使用类型安全的参数执行查询 // SQL-like 语法 + 参数占位符，编译期保证安全 result := sql db { select from User where age > 18 && is_active == true limit 10 }! // Spring 等价：jdbcTemplate.query(sql, params, rowMapper) // Laravel 等价：DB::select('SELECT * FROM users WHERE age > ?', [18])
🚀 生产实践
  • 始终嵌入 Touchable 让 Photon 自动管理 created_at / updated_at
  • 使用 before_insert 做数据校验，而非在 Controller 层做
  • 多库场景下用 OrmManager 路由：写操作走 master，读操作走 replica
  • 派生查询适合简单查询，复杂查询使用 OrmAdapter + 手写 SQL 或 QueryBuilder 链式 API
  • 使用 @[entity] + @[table] + @[column] 注解实现编译期实体映射，避免手写 SQL
  • 使用 validate[T]() 在 Service 层做数据校验，而非在 Controller 层
  • 使用 paginate() 实现标准分页，返回 PageResult[T] 包含完整分页元数据
  • 使用 ParamValue + set_typed_exec_fn 实现类型安全的参数化查询，防止 SQL 注入
